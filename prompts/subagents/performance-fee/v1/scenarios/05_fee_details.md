# 5. 수수료 내역 조회

로그인한 카드 모집인 본인이 실제로 지급받은 수수료·수당, 부과된 세금과 공제,
최종 실지급액, 장기 지급 추이 또는 원천징수 내역을 조회하려는 질문이다.
지점장이 다른 모집인의 지급 내역을 조회하는 업무가 아니다.

## FEE_ITEM_DETAILS

- 본인에게 지급된 항목별 수수료 또는 수당 내역
- 세금·실지급액·추이·원천징수 한정 없이 "내 수수료", "수수료가 궁금해"라고
  묻는 일반 수수료 조회
- 같은 질문에 실적 조회도 있으면 이 세부 시나리오를 유지한 채
  `PERFORMANCE_SUMMARY_TOTAL`을 별도 match로 추가한다.
- 단, 패널티·회입·환수·삭감·차감의 실제 금액은 일반 항목별 수수료가 아니라
  `DISPOSAL_FEE_SUMMARY`를 선택한다.
- 파라미터: closing_year_month

## FEE_TAX_NET_PAYMENT

- 본인 수수료에 부과된 항목별 세금·공제와 실제 지급액·입금액
- 파라미터: closing_year_month

## FEE_12_MONTH_TREND

- 본인이 실제 지급받은 최근 12개월 또는 1년 수수료 변화와 추이
- 파라미터: closing_year_month

## WITHHOLDING_TAX

- 본인에게 지급된 수수료의 연도별 원천징수 내역
- 원천징수 내역을 화면에서 조회하거나 다시 보여 달라는 요청
- 파라미터: reference_year

## WITHHOLDING_TAX_FAX_SEND

- 조회된 원천징수 내역을 팩스로 보내거나 팩스 전송 절차를 시작하는 요청
- `팩스로 전송해드릴까요?`, `팩스로 보내줘`, `다른 팩스번호로 다시 보내줘`는
  조회가 아니라 이 세부 시나리오를 선택한다.
- 원천징수 조회의 추천질문을 클릭하거나 직후 `네`라고 답하면 이 detail을
  LLM 추측 없이 직접 선택한다. 추천질문 선택 자체가 전송 의사 표시이므로 별도
  승인 parameter/action을 만들지 않는다.
- 최초 분류에서는 사용자가 한 문장에 직접 제공한 팩스번호만 추출한다. 값이
  없거나 형식이 잘못되면 Python 시나리오 함수가 팩스번호 action을 반환한다.
- 파라미터: reference_year, fax_number
